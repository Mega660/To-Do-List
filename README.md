Vanilla JavaScript To-Do List App

A simple, interactive, and user-friendly To-Do List web application built using pure (Vanilla) JavaScript, HTML, and CSS. This project demonstrates core JavaScript concepts such as DOM manipulation, event handling, and dynamic content creation without using any external libraries or frameworks.

🚀 Features

- Add new tasks
- Mark tasks as completed (green check icon with cross-through)
- Delete tasks
- Scrollable task container (prevents layout expansion)
- Clean and modern user interface
- Built with pure Vanilla JavaScript (no frameworks)

🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- DOM Manipulation
